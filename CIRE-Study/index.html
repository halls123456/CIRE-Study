Deploy to GitHub Pages in 2 Minutes

This entire exam prep platform is 100% static, client-side, and requires no backend server or build pipeline. You can upload it to GitHub and have your personal exam prep site live immediately.

1
Create a new GitHub Repository

Log in to GitHub.com, click New Repository, name it (e.g. ciro-cire-exam-prep), and keep it Public or Private.

2
Upload / Push your project files

Upload all files in this project folder (including index.html, css/, js/, data/) to the repository branch (e.g. main).

git init
git add .
git commit -m "Deploy CIRE unique questions exam prep"
git branch -M main
git remote add origin https://github.com/<your-username>/ciro-cire-exam-prep.git
git push -u origin main
3
Enable GitHub Pages in Settings

Go to your repository's Settings > Pages. Under Build and deployment, set Source to Deploy from a branch, select main branch and / (root), and click Save.

Within 60 seconds, your site will be live at: https://<your-username>.github.io/ciro-cire-exam-prep/
